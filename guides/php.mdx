Server-side script loading packages for PHP applications, providing secure, cached script loading with framework-specific integrations for Laravel and Symfony.

<Warning>
  Every rendered `<script>` tag **must** include a `data-code` attribute set
  to your Account ID (verification code). AdUnblock uses this value to verify
  that the script is running on your registered domain. Find your Account ID
  at the top of your AdUnblock dashboard.
</Warning>

## Expected Remote Response Format

All PHP packages expect the remote URL to return JSON in this format:

```json
["https://example.com/script1.js", "https://example.com/script2.js"]
```

## Laravel Integration

A Laravel package to fetch and render scripts from a remote URL with caching support.

**Repository**: [github.com/adunblock/adunblock-server-tag-laravel](https://github.com/adunblock/adunblock-server-tag-laravel)

### Installation

Install the package via Composer:

```bash
composer require adunblock/server-tag-laravel:^1.2
```

The package will be automatically registered via Laravel's package auto-discovery feature.

<Note>
Version 1.0+ is a stable release and doesn't require lowering `minimum-stability` in your `composer.json`.
</Note>

### Basic Usage

In your Blade template, call the `server_tag` function with your Account ID
(verification code) in the fourth argument:

```php
<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
  {!!
    server_tag(
      'https://public.adunblocker.com/api/vendor_scripts',
      300,
      null,
      ['data-code' => 'YOUR_ACCOUNT_ID']
    )
  !!}
</head>
<body>
  <h1>My Page</h1>
</body>
</html>
```

It prints one tag, for the preferred script URL:

```html
<script data-cfasync="false" nowprocket src="SCRIPT_URL" async data-code="YOUR_ACCOUNT_ID"></script>
```

`data-cfasync="false"` and `nowprocket` come before `src`, which is what keeps
Cloudflare Rocket Loader and WP Rocket's Delay JavaScript Execution off the tag.

### Your site's domain

The helper sends your site's domain to us as `?domain=`, taken from the current
request's host. The domain lets us move your site alone to a new script host
when an ad blocker rule targets it (see [Fetch Config](/api-reference/fetch-config#query-parameters)).
The cache is kept per domain, so each site of a multi-site install gets its own
answer. To send a different domain, pass it as the fifth argument, or leave a
`?domain=` in the URL: it is kept as written.

### With Caching

The second argument is the cache duration in seconds (default: `300`):

```php
{!!
  server_tag(
    'https://public.adunblocker.com/api/vendor_scripts',
    600,
    null,
    ['data-code' => 'YOUR_ACCOUNT_ID']
  )
!!}
```

This caches the response for 10 minutes (600 seconds).

### Custom Rendering

The default tag is the one to use. If you need to print it yourself, pass a
closure as the third argument. It receives the script URLs, preferred first:
print only the first, keep `data-cfasync="false"` and `nowprocket` before
`src`, keep `data-code`, and load it with `async`:

```php
{!!
  server_tag(
    'https://public.adunblocker.com/api/vendor_scripts',
    300,
    function (array $scripts) {
      if (empty($scripts)) {
        return '';
      }
      return sprintf(
        '<script data-cfasync="false" nowprocket src="%s" async data-code="YOUR_ACCOUNT_ID"></script>',
        e($scripts[0])
      );
    }
  )
!!}
```

### Function Signature

```php
server_tag(
    string $url,
    int $cache_seconds = 300,
    ?callable $render_script = null,
    ?array $script_attributes = null,
    ?string $domain = null
): string
```

**Parameters:**
- `$url` (string): The remote URL to fetch scripts from
- `$cache_seconds` (int, optional): Cache duration in seconds. Default is `300`
- `$render_script` (callable, optional): Custom rendering function. Receives an array of script URLs and returns an HTML string
- `$script_attributes` (array, optional): Associative array of attributes added to the `<script>` tag after `src`. **Must include `'data-code' => YOUR_ACCOUNT_ID`.** `data-cfasync="false"`, `nowprocket` and `async` are printed by default; set one to `false` to drop it
- `$domain` (string, optional): Your site's domain. Default is the current request's host

### Laravel Features

- **Blade Helper Function**: Easy-to-use function for templates
- **Built-in Caching**: Automatic caching with configurable TTL
- **Auto-discovery**: Automatic service provider registration
- **Error Handling**: Graceful fallback to empty arrays
- **Security**: XSS protection with proper HTML escaping

### Laravel Requirements

- PHP 7.4 or higher
- Laravel 8/9/10/11/12

## Symfony Integration

A Symfony bundle to fetch and render scripts from a remote URL with Twig integration and caching support.

**Repository**: [github.com/adunblock/adunblock-server-tag-symfony](https://github.com/adunblock/adunblock-server-tag-symfony)

### Installation

Install the bundle via Composer:

```bash
composer require adunblock/server-tag-symfony:^1.1
```

<Note>
Version 1.0+ is a stable release and doesn't require lowering `minimum-stability` in your `composer.json`.
</Note>

Enable the bundle in your `config/bundles.php`:

```php
<?php

return [
    // ... other bundles
    AdUnblock\ServerTag\Symfony\AdunblockServerTagBundle::class => ['all' => true],
];
```

### Basic Usage

In your Twig template, call `server_tag` with your Account ID (verification
code) in `scriptAttributes`:

```twig
<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
  {{ server_tag('https://public.adunblocker.com/api/vendor_scripts', scriptAttributes={'data-code': 'YOUR_ACCOUNT_ID'}) }}
</head>
<body>
  <h1>My Page</h1>
</body>
</html>
```

It prints one tag, for the preferred script URL:

```html
<script data-cfasync="false" nowprocket src="SCRIPT_URL" async data-code="YOUR_ACCOUNT_ID"></script>
```

`data-cfasync="false"` and `nowprocket` come before `src`, which is what keeps
Cloudflare Rocket Loader and WP Rocket's Delay JavaScript Execution off the tag.

### Your site's domain

The bundle sends your site's domain to us as `?domain=`, taken from the current
request's host. The domain lets us move your site alone to a new script host
when an ad blocker rule targets it (see [Fetch Config](/api-reference/fetch-config#query-parameters)).
The cache is kept per domain, so each site of a multi-site install gets its own

`?domain=` in the URL: it is kept as written.

### With Caching

The second argument is the cache duration in seconds (default: `300`, 5 minutes):

```twig
{{ server_tag('https://public.adunblocker.com/api/vendor_scripts', 600, null, {'data-code': 'YOUR_ACCOUNT_ID'}) }}
```

### Function Signature

```php
server_tag(
    string $url,
    int $cache_seconds = 300,
    ?callable $render_script = null,
    ?array $script_attributes = null,
    ?string $domain = null
): string
```

In Twig the named arguments are `remoteUrl`, `cacheInterval`, `renderScript`,
`scriptAttributes` and `domain`.

**Parameters:**
- `$url` (string): The remote URL to fetch scripts from
- `$cache_seconds` (int, optional): Cache duration in seconds. Default is `300`
- `$render_script` (callable, optional): Custom rendering function. Receives an array of script URLs and returns an HTML string
- `$script_attributes` (array, optional): Attributes added to the `<script>` tag after `src`. **Must include `'data-code': YOUR_ACCOUNT_ID`.** `data-cfasync="false"`, `nowprocket` and `async` are printed by default; set one to `false` to drop it
- `$domain` (string, optional): Your site's domain. Default is the current request's host
