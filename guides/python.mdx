Server-side script loading package for Python applications, providing secure, cached script loading with Django template tag integration.

## Django Integration

A Django package to fetch and render scripts from a remote URL with template tag integration and caching support.

### Installation

Install the package via pip:

```bash
pip install "adunblock-server-tag-django>=1.2"
```

<Warning>
  Every rendered `<script>` tag **must** include a `data-code` attribute set
  to your Account ID (verification code). AdUnblock uses this value to verify
  that the script is running on your registered domain. Find your Account ID
  at the top of your AdUnblock dashboard.
</Warning>

Add the `server_tag` app to your `INSTALLED_APPS` in your Django `settings.py`:

```python
INSTALLED_APPS = [
    # ... other apps
    'server_tag',
]
```

### Cache Configuration

Configure caching in your `settings.py` (recommended for production):

#### Redis Cache (Production)

```python
CACHES = {
    'default': {
        'BACKEND': 'django.core.cache.backends.redis.RedisCache',
        'LOCATION': 'redis://127.0.0.1:6379/1',
    }
}
```

#### Local Memory Cache (Development)

```python
CACHES = {
    'default': {
        'BACKEND': 'django.core.cache.backends.locmem.LocMemCache',
        'LOCATION': 'unique-snowflake',
    }
}
```

### Basic Usage

A Django template can't write a dictionary, so give every template your Account
ID with a context processor:

```python
# my_app/context_processors.py
def adunblock(request):
    return {'server_tag_attrs': {'data-code': 'YOUR_ACCOUNT_ID'}}
```

```python
# settings.py
TEMPLATES = [
    {
        # ...
        'OPTIONS': {
            'context_processors': [
                # ... the ones you have, with django.template.context_processors.request
                'my_app.context_processors.adunblock',
            ],
        },
    },
]
```

Then in your Django template, load the `server_tag_tags` and use the
`server_tag` tag with the `script_attributes` argument:

```html
{% load server_tag_tags %}

<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
  {% server_tag "https://public.adunblocker.com/api/vendor_scripts" script_attributes=server_tag_attrs %}
</head>
<body>
  <h1>My Page</h1>
</body>
</html>
```

It prints one tag, for the preferred script URL:

```html
<script data-cfasync="false" nowprocket src="SCRIPT_URL" async data-code="YOUR_ACCOUNT_ID"></script>
```

`data-cfasync="false"` and `nowprocket` come before `src`, which is what keeps
Cloudflare Rocket Loader and WP Rocket's Delay JavaScript Execution off the tag.

### Your Site's Domain

The tag sends your site's domain to us as `?domain=`, taken from
`request.get_host()`. It needs the `request` in the template context, which the
`django.template.context_processors.request` context processor provides (on in
new projects). When an ad blocker rule targets your site, we move your site
alone to a new script host, and only a request that names your site receives it
(see [Fetch Config](/api-reference/fetch-config#query-parameters)). The cache is
kept per domain, so each site of a multi-site install gets its own answer. To
send a fixed domain, add `domain="example.com"` to the tag.

### Custom Rendering

The default tag is the one to use. If you need to print it yourself, pass a
Python function as `render_script`. The function receives `{'js': [...]}`, the
script URLs with the preferred one first. Print only the first, keep
`data-cfasync="false"` and `nowprocket` before `src`, keep `data-code`, and
load it with `async`.

#### Add the Renderer to the Context Processor

```python
# my_app/context_processors.py
from django.utils.html import escape


def render_adunblock(js_files):
    sources = js_files.get('js') or []
    if not sources:
        return ''
    return (
        f'<script data-cfasync="false" nowprocket src="{escape(sources[0])}" '
        f'async data-code="YOUR_ACCOUNT_ID"></script>'
    )


def adunblock(request):
    return {
        # ... server_tag_attrs, as above
        'adunblock_render': render_adunblock,
    }
```

#### Use It in the Template

```html
{% load server_tag_tags %}

<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
  {% server_tag "https://public.adunblocker.com/api/vendor_scripts" render_script=adunblock_render %}
</head>
<body>
  <h1>My Page</h1>
</body>
</html>
```

## Expected Remote Response Format

The remote URL should return a JSON response in this format:

```json
[
  "https://example.com/script1.js",
  "https://example.com/script2.js"
]
```

## Advanced Usage

### Template Tag with Cache Control

```html
{% load server_tag_tags %}

<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
  {% server_tag "https://public.adunblocker.com/api/vendor_scripts" cache_interval=600 script_attributes=server_tag_attrs %}
</head>
<body>
  <h1>My Page</h1>
</body>
</html>
```

### Conditional Script Loading

```html
{% load server_tag_tags %}

<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
  {% if user.is_authenticated %}
    {% server_tag "https://public.adunblocker.com/api/vendor_scripts" script_attributes=server_tag_attrs %}
  {% else %}
    {% server_tag "https://public.adunblocker.com/api/vendor_scripts" script_attributes=server_tag_attrs %}
  {% endif %}
</head>
<body>
  <h1>My Page</h1>
</body>
</html>
```

### Using in Class-Based Views

```python
from django.views.generic import TemplateView
from django.template.loader import render_to_string

class MyView(TemplateView):
    template_name = 'my_template.html'

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)

        # You can also use the server_tag functionality in views
        context['page_title'] = 'My Custom Page'

        return context
```

## Configuration Options

The Django package supports several configuration options:

### Settings Configuration

You can configure default settings in your `settings.py`:

```python
# Optional: Configure default cache timeout
SERVER_TAG_DEFAULT_TIMEOUT = 300  # 5 minutes

# Optional: Configure default HTTP timeout
SERVER_TAG_HTTP_TIMEOUT = 10  # 10 seconds

# Optional: Configure retry attempts
SERVER_TAG_RETRY_ATTEMPTS = 3
```

### Template Tag Parameters

The `server_tag` template tag accepts these parameters:

| Parameter           | Type       | Default  | Description                                                                                           |
| ------------------- | ---------- | -------- | ----------------------------------------------------------------------------------------------------- |
| `remote_url`        | `string`   | Required | URL to fetch script configuration from                                                                |
| `cache_interval`    | `number`   | `300`    | Cache duration in seconds                                                                             |
| `script_attributes` | `dict`     | `None`   | Attributes added to the tag after `src`. **Must include `'data-code': YOUR_ACCOUNT_ID`.** `data-cfasync`, `nowprocket` and `async` are on by default; set one to `False` to drop it |
| `render_script`     | `function` | `None`   | Custom script rendering function                                                                      |
| `domain`            | `string`   | request host | Your site's domain, sent as `?domain=`                                                            |

## Security Considerations

- **URL Validation**: Only HTTP and HTTPS URLs are allowed
- **XSS Protection**: All output is properly escaped using Django's built-in functions
- **Error Handling**: Failed requests don't break template rendering
- **Caching**: Reduces load on remote servers and improves performance

## Performance Tips

1. **Use Redis**: Configure Redis caching for production environments
2. **Cache Warming**: Pre-warm caches during deployment
3. **Error Monitoring**: Monitor failed requests and adjust retry logic
4. **CDN Usage**: Use CDN URLs for better performance

## Requirements

- Python 3.8 or higher
- Django 3.2 or higher
- requests 2.25.0 or higher

## Common Patterns

### Base Template with Server Tags

```html
<!-- base.html -->
{% load server_tag_tags %}

<!DOCTYPE html>
<html>
<head>
  <title>{% block title %}My Site{% endblock %}</title>
  {% server_tag "https://public.adunblocker.com/api/vendor_scripts" script_attributes=server_tag_attrs %}
  {% block extra_scripts %}{% endblock %}
</head>
<body>
  {% block content %}{% endblock %}
</body>
</html>
```

### Page-Specific Scripts

```html
<!-- specific_page.html -->
{% extends "base.html" %}
{% load server_tag_tags %}

{% block extra_scripts %}
  {% server_tag "https://public.adunblocker.com/api/vendor_scripts" script_attributes=server_tag_attrs %}
{% endblock %}

{% block content %}
  <h1>Specific Page Content</h1>
{% endblock %}
```
