A Next.js React Server Component for fetching and rendering external JavaScript files on the server-side before page rendering. This package provides secure, cached script loading with TypeScript support.

## Installation

```bash
npm install @adunblock/server-tag-nextjs
```

<Warning>
  Every rendered `<script>` tag **must** include a `data-code` attribute set
  to your Account ID (verification code). AdUnblock uses this value to verify
  that the script is running on your registered domain. Find your Account ID
  at the top of your AdUnblock dashboard.
</Warning>

<Tip>
  **Send your site's domain.** Add `?domain=` and your domain to `remoteUrl`.
  When an ad blocker rule targets your site, we move your site alone to a new
  script host, and only a request that names your site receives it. See
  [Fetch Config](/api-reference/fetch-config#query-parameters).
</Tip>

## Basic Usage

Import and use the `ServerTag` component in your Next.js pages or layouts:

```tsx
import ServerTag from "@adunblock/server-tag-nextjs";

export default function MyPage() {
  return (
    <div>
      <ServerTag
        // Your own domain in place of example.com
        remoteUrl="https://public.adunblocker.com/api/vendor_scripts?domain=example.com"
        scriptAttributes={{ "data-code": "YOUR_ACCOUNT_ID" }}
      />
      <h1>My Page Content</h1>
    </div>
  );
}
```

### Several sites on one app

Read the host off the request, so each site sends its own domain. The cache is kept per URL, so every site still gets its own cached answer:

```tsx
import { headers } from "next/headers";
import ServerTag from "@adunblock/server-tag-nextjs";

export default async function RootLayout({ children }: { children: React.ReactNode }) {
  const host = (await headers()).get("host") ?? "";
  return (
    <html>
      <body>
        <ServerTag
          remoteUrl={`https://public.adunblocker.com/api/vendor_scripts?domain=${encodeURIComponent(host)}`}
          scriptAttributes={{ "data-code": "YOUR_ACCOUNT_ID" }}
        />
        {children}
      </body>
    </html>
  );
}
```

### Behind Cloudflare Rocket Loader

Rocket Loader skips a script only when `data-cfasync="false"` comes **before** `src`, and the default tag prints `src` first. If your site runs Rocket Loader, print the tag yourself with `renderScript`, as in [Custom Script Rendering](#custom-script-rendering).

## Advanced Usage

### Custom Caching

```tsx
import ServerTag from "@adunblock/server-tag-nextjs";

export default function MyPage() {
  return (
    <div>
      <ServerTag
        remoteUrl="https://public.adunblocker.com/api/vendor_scripts?domain=example.com"
        cacheInterval={600} // Cache for 10 minutes (default: 300 seconds)
        scriptAttributes={{ "data-code": "YOUR_ACCOUNT_ID" }}
      />
      <h1>My Page Content</h1>
    </div>
  );
}
```

### Custom Script Rendering

Override the default script rendering with a custom callback. It receives `{ js: string[] }`, the script URLs with the preferred one first. Keep `data-cfasync="false"` and `nowprocket` before `src`, keep `data-code`, and load it right away (`async`): a deferred or lazy strategy loads AdUnblock after your ads have already been blocked.

```tsx
import ServerTag from "@adunblock/server-tag-nextjs";

export default function MyPage() {
  return (
    <div>
      <ServerTag
        remoteUrl="https://public.adunblocker.com/api/vendor_scripts?domain=example.com"
        renderScript={({ js }) =>
          js.slice(0, 1).map((src) => (
            <script
              key={src}
              data-cfasync="false"
              nowprocket=""
              src={src}
              async
              data-code="YOUR_ACCOUNT_ID"
            />
          ))
        }
      />
      <h1>My Page Content</h1>
    </div>
  );
}
```

## API Reference

### Props

| Prop               | Type                | Default     | Description                                                                                        |
| ------------------ | ------------------- | ----------- | -------------------------------------------------------------------------------------------------- |
| `remoteUrl`        | `string`            | Required    | The URL to fetch script URLs from                                                                  |
| `cacheInterval`    | `number`            | `300`       | Cache duration in seconds                                                                          |
| `scriptAttributes` | `ScriptAttributes`  | `undefined` | Attributes applied to every generated `<script>` tag. **Must include `data-code: YOUR_ACCOUNT_ID`.** |
| `renderScript`     | `function`          | `undefined` | Custom script rendering function                                                                   |

### Types

```typescript
type ScriptAttributeValue = string | boolean | number | undefined;

interface ScriptAttributes {
  [key: string]: ScriptAttributeValue;
}

interface ServerTagProps {
  remoteUrl: string;
  cacheInterval?: number;
  scriptAttributes?: ScriptAttributes;
  renderScript?: (jsFiles: { js: string[] }) => React.ReactNode;
}
```

## Security

- Only HTTP and HTTPS URLs are allowed
- Server-side execution prevents client-side script injection
- URL validation prevents malicious protocol usage

## Browser Compatibility

This package works with all browsers supported by Next.js 15+ and React 19.
