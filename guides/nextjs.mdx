A Next.js React Server Component for fetching and rendering external JavaScript files on the server-side before page rendering. This package provides secure, cached script loading with TypeScript support.

## Installation

```bash
npm install @adunblock/server-tag-nextjs@^1.2
```

<Warning>
  Every rendered `<script>` tag **must** include a `data-code` attribute set
  to your Account ID (verification code). AdUnblock uses this value to verify
  that the script is running on your registered domain. Find your Account ID
  at the top of your AdUnblock dashboard.
</Warning>

## Basic Usage

Import and use the `ServerTag` component in your Next.js pages or layouts:

```tsx
import ServerTag from "@adunblock/server-tag-nextjs";

export default function MyPage() {
  return (
    <div>
      <ServerTag
        remoteUrl="https://public.adunblocker.com/api/vendor_scripts"
        scriptAttributes={{ "data-code": "YOUR_ACCOUNT_ID" }}
      />
      <h1>My Page Content</h1>
    </div>
  );
}
```

It prints one tag, for the preferred script URL, which React places in `<head>`:

```html
<script data-cfasync="false" nowprocket="" src="SCRIPT_URL" async="" data-code="YOUR_ACCOUNT_ID"></script>
```

`data-cfasync="false"` and `nowprocket` come before `src`, which is what keeps
Cloudflare Rocket Loader and WP Rocket's Delay JavaScript Execution off the tag.

### Your site's domain

The component sends your site's domain to us as `?domain=`, read from the
request's `x-forwarded-host` or `host` header. When an ad blocker rule targets
your site, we move your site alone to a new script host, and only a request
that names your site receives it (see [Fetch Config](/api-reference/fetch-config#query-parameters)).
The cache is kept per domain, so each site of a multi-site app gets its own
answer.

Reading the request makes the route render on every request. To keep a page
static, pass the domain yourself:

```tsx
<ServerTag
  remoteUrl="https://public.adunblocker.com/api/vendor_scripts"
  domain="example.com"
  scriptAttributes={{ "data-code": "YOUR_ACCOUNT_ID" }}
/>
```

A static page keeps the script URL it was built with until it is rebuilt or
revalidated, so give it a `revalidate` (for example `export const revalidate = 300`).

## Advanced Usage

### Custom Caching

```tsx
import ServerTag from "@adunblock/server-tag-nextjs";

export default function MyPage() {
  return (
    <div>
      <ServerTag
        remoteUrl="https://public.adunblocker.com/api/vendor_scripts"
        cacheInterval={600} // Cache for 10 minutes (default: 300 seconds)
        scriptAttributes={{ "data-code": "YOUR_ACCOUNT_ID" }}
      />
      <h1>My Page Content</h1>
    </div>
  );
}
```

### Custom Script Rendering

The default tag is the one to use. If you need to print it yourself, pass a callback. It receives `{ js: string[] }`, the script URLs with the preferred one first. Print only the first, keep `data-cfasync="false"` and `nowprocket` before `src`, keep `data-code`, and load it right away (`async`): a deferred or lazy strategy loads AdUnblock after your ads have already been blocked.

```tsx
import ServerTag from "@adunblock/server-tag-nextjs";

export default function MyPage() {
  return (
    <div>
      <ServerTag
        remoteUrl="https://public.adunblocker.com/api/vendor_scripts"
        renderScript={({ js }) =>
          js.slice(0, 1).map((src) => (
            <script
              key={src}
              data-cfasync="false"
              nowprocket=""
              src={src}
              async
              data-code="YOUR_ACCOUNT_ID"
            />
          ))
        }
      />
      <h1>My Page Content</h1>
    </div>
  );
}
```

## API Reference

### Props

| Prop               | Type                | Default     | Description                                                                                        |
| ------------------ | ------------------- | ----------- | -------------------------------------------------------------------------------------------------- |
| `remoteUrl`        | `string`            | Required    | The URL to fetch script URLs from                                                                  |
| `cacheInterval`    | `number`            | `300`       | Cache duration in seconds                                                                          |
| `domain`           | `string`            | request host | Your site's domain, sent as `?domain=`. Pass it to keep a page static                              |
| `scriptAttributes` | `ScriptAttributes`  | `undefined` | Attributes added to the tag after `src`. **Must include `data-code: YOUR_ACCOUNT_ID`.** `data-cfasync`, `nowprocket` and `async` are on by default; set one to `false` to drop it |
| `renderScript`     | `function`          | `undefined` | Custom script rendering function                                                                   |

### Types

```typescript
type ScriptAttributeValue = string | boolean | number | undefined;

interface ScriptAttributes {
  [key: string]: ScriptAttributeValue;
}

interface ServerTagProps {
  remoteUrl: string;
  cacheInterval?: number;
  domain?: string;
  scriptAttributes?: ScriptAttributes;
  renderScript?: (jsFiles: { js: string[] }) => React.ReactNode;
}
```

## Security

- Only HTTP and HTTPS URLs are allowed
- Server-side execution prevents client-side script injection
- URL validation prevents malicious protocol usage

## Browser Compatibility

This package works with all browsers supported by Next.js 15+ and React 19.
