# Configuration API Reference

The AdUnblock Configuration API returns the current URL of the AdUnblock script for your site. Script hosts change when ad blockers add rules against them, so resolve the URL on your server when your page renders instead of hardcoding it.

## Base URL

```
https://public.adunblocker.com
```

## Authentication

This API endpoint is publicly accessible and does not require authentication.

## Server Tag Configuration

### Get JavaScript Configuration

Retrieve the current script URL for your site.

<CodeGroup>
```bash cURL
curl "https://public.adunblocker.com/api/vendor_scripts?domain=example.com"
```

```javascript JavaScript
const response = await fetch(
  "https://public.adunblocker.com/api/vendor_scripts?domain=example.com"
);
const scripts = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://public.adunblocker.com/api/vendor_scripts',
    params={'domain': 'example.com'},
    timeout=3,
)
scripts = response.json()
```

</CodeGroup>

#### Query Parameters

| Parameter | Required | Description |
| --------- | -------- | ----------- |
| `domain`  | No, but recommended | Your site's domain, as your visitors see it (`example.com`). |

**Always send `domain`.** Many ad blocker rules block a script host only on the sites they name. When a rule targets your site, we publish a new host for your site alone, and only a request that names your site receives it. Without `domain`, your site gets the shared default URL, which for such a rule is exactly the host blocked for you.

- **Send the host of the page being rendered**, not your origin server, CDN hostname or ad server: `$_SERVER['HTTP_HOST']` in PHP, `req.hostname` in Express, `request.get_host()` in Django.
- **Just the host.** A full URL, uppercase, a port or `www.` are normalized for you, and `www.example.com` resolves to `example.com`.
- **Multi-site installs:** read the host off each request, and every site gets its own answer.
- **A missing or unknown domain is never an error.** You get the default list, as integrations that predate the parameter do.

If we gave you a sources URL with a vendor segment (`/api/vendor_scripts/<vendor>`), keep it and add `domain` to it.

#### Response

```json
["https://cdn.example.com/detection-script.js"]
```

#### Response Format

A JSON array of script URLs, most preferred first. Use the first one. The shape is the same with or without `domain`: only the URLs inside can differ.

#### Response Headers

| Header          | Description                                                   |
| --------------- | ------------------------------------------------------------- |
| `Content-Type`  | `application/json`                                            |
| `Cache-Control` | `public, max-age=0, must-revalidate`                          |
| `ETag`          | Changes only when the list for your site changes              |

The endpoint honors `If-None-Match` and answers `304 Not Modified` when the list hasn't changed, so revalidating is cheap.

#### Using the Response

Print the tag from your server, in `<head>` and before your ad code, with the first URL as `src`. Keep the attributes from your dashboard's tag, with `data-cfasync="false"` and `nowprocket` before `src` (see [Page optimizers](/guides/html-javascript#page-optimizers)):

```html
<script data-cfasync="false" nowprocket src="FIRST_URL_FROM_THE_RESPONSE" async data-code="YOUR_ACCOUNT_ID"></script>
```

Four rules, whatever your stack:

1. **Cache the URL for about 5 minutes.** The lookup sits on your page view path.
2. **Cache a failure too**, for about 30 seconds, and use a short timeout (about 3 seconds), so an outage can't slow every page view.
3. **Never hardcode a fallback URL.** A host we have moved away from recovers nothing, and nothing on your page would say so. Render no tag and log it instead.
4. **Don't fetch it from the browser.** Ad blockers act in the browser, and a client-side lookup runs too late to help your ads.

```javascript
// Node.js: revalidate with the ETag you kept (cache it with what you already run)
let cached = { etag: null, scripts: [], at: 0 };

async function currentScript(host) {
  if (Date.now() - cached.at < 5 * 60 * 1000) return cached.scripts[0];
  const response = await fetch(
    `https://public.adunblocker.com/api/vendor_scripts?domain=${encodeURIComponent(host)}`,
    {
      headers: cached.etag ? { "If-None-Match": cached.etag } : {},
      signal: AbortSignal.timeout(3000),
    }
  );
  if (response.status !== 304) {
    cached.scripts = await response.json();
    cached.etag = response.headers.get("ETag");
  }
  cached.at = Date.now();
  return cached.scripts[0];
}
```

For a multi-site install, keep one cache entry per host.

## Valid Script Sources (Deprecated)

<Warning>
  This endpoint is deprecated and will be removed in a future version. Please
  use the `/api/vendor_scripts` endpoint instead.
</Warning>

### Get Valid Script Sources

Retrieve a list of valid JavaScript source URLs for ad blocker detection.

<CodeGroup>
```bash cURL
curl -X GET https://config.adunblocker.com/valid_script_sources.json
```

```javascript JavaScript
const response = await fetch(
  "https://config.adunblocker.com/valid_script_sources.json"
);
const sources = await response.json();
```

```python Python
import requests

response = requests.get('https://config.adunblocker.com/valid_script_sources.json')
sources = response.json()
```

</CodeGroup>

#### Response

```json
["https://cdn.example.com/detection-script.js"]
```

#### Response Format

The response is a JSON array containing valid JavaScript source URLs as strings.

#### Response Headers

| Header          | Description                                       |
| --------------- | ------------------------------------------------- |
| `Content-Type`  | `application/json`                                |
| `ETag`          | Entity tag for caching validation                 |
| `Last-Modified` | Timestamp when the configuration was last updated |

#### Migration Guide

If you're currently using this endpoint, migrate to the new `/api/vendor_scripts` endpoint:

```javascript
// Old (deprecated)
const sources = await fetch(
  "https://config.adunblocker.com/valid_script_sources.json"
).then((response) => response.json());

// New (recommended)
const scripts = await fetch(
  "https://public.adunblocker.com/api/vendor_scripts"
).then((response) => response.json());
// scripts is already an array, no need to access .js property
```
